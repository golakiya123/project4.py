## 📌 Project Overview

**Data Analyzer & Transformer** is a beginner-friendly command-line Python application that allows users to enter a dataset and perform different operations such as viewing a summary, calculating factorials, filtering values, sorting data, and displaying dataset statistics.

The program uses a simple menu system so that each feature can be selected easily.

## ✨ Features

- 📥 **Input Data** — Enter multiple integer values at once.
- 📊 **Display Data Summary** — View the number of elements, minimum, maximum, sum, and average.
- 🧮 **Calculate Factorial** — Calculate the factorial of a number using recursion.
- 🔎 **Filter Data by Threshold** — Display values greater than or equal to a chosen threshold.
- 🔢 **Sort Data** — Sort the dataset in ascending or descending order.
- 📈 **Dataset Statistics** — Display minimum, maximum, sum, and average.
- 🚪 **Exit Program** — Close the application safely.

## 🛠️ Technologies Used

- **Python 3**
- Lists
- Functions
- Recursion
- Conditional statements
- Loops
- List comprehensions
- Built-in functions such as `min()`, `max()`, `sum()`, and `sorted()`
